Sidebar

Complementary content that is tangentially related to the main content. Used for sidebars, related links, advertising, or supplementary information.

Also known as
Aside. In design systems: UI shell left panel (Carbon); Side navigation (Atlassian); Sidebar (shadcn/ui)
Semantic element
<aside>
Category
A. Page structure

Layout Variations

Usage Notes

  • Use for content that supplements but isn't essential to the main content.
  • On mobile, sidebars typically collapse into a drawer or move below main content.
  • Do not use Sidebar for primary navigation — use Navigation in Header instead.
