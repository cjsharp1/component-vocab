Tabs

Content organized into switchable panels. Only one panel is visible at a time; tab buttons switch between them.

Also known as
Tabbed interface. In design systems: Tabs (MUI, Ant Design, Carbon, Atlassian, Chakra UI, Radix Themes, shadcn/ui, GOV.UK); Navs & tabs (Bootstrap); Tablist (Fluent UI); Tab views (Apple HIG)
Semantic element

Usage Notes

  • Use when content is mutually exclusive — user views one section at a time.
  • For progressive disclosure (FAQ), use Accordion.
  • Keep tab count under 7. If you need more, consider a different pattern (Menu button, Sidebar navigation).
  • Always show which tab is currently active with a clear visual indicator.
