Table

Tabular data presented in rows and columns. For structured data that benefits from alignment and comparison across rows.

Usage Notes

  • Use for structured data. For feature comparisons, prefer Comparison. For key-value pairs, use Snapshot.
  • Keep tables simple — if it needs many interactive features, it's probably an app data grid.
  • Always include a header row to label columns.
  • For responsive tables on small screens, use horizontal scroll or stack into cards.
