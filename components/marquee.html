Marquee

A continuously scrolling horizontal strip of content. Used for logos, headlines, announcements, or image feeds that animate endlessly.

Usage Notes

  • Use sparingly — constant motion can be distracting. Provide a pause mechanism for accessibility (pause on hover at minimum). For static logo display, prefer Logo Cloud.
  • Always duplicate content seamlessly so the loop is continuous without gaps.
  • Respect prefers-reduced-motion media query — disable animation for users who prefer reduced motion.
  • Use aria-live="off" to prevent screen readers from announcing every item as it scrolls.
  • Consider performance — too many or too large items can cause jank on lower-end devices.
