Toast

A temporary, non-blocking notification message that appears briefly and then auto-dismisses. For lightweight feedback that doesn't interrupt the user's flow.

Also known as
Snackbar. In design systems: Snackbar (MUI); Toasts (Bootstrap); Message (Ant Design); Flag (Atlassian); Toast (Chakra UI, shadcn/ui, Fluent UI)
Semantic element
<div> with role="status"
Category

Usage Notes

  • Use for non-critical confirmations ("Saved!", "Copied!").
  • For important feedback, use Alert (stays visible).
  • For blocking actions, use a modal Dialog.
  • Keep messages short — toasts are meant to be glanceable.
