Navigation

Primary navigation menu presenting the main site structure. Contains links to top-level pages organized as a horizontal or vertical list.

Also known as
Nav, Menu. In design systems: Navbar (Bootstrap); Menu (Ant Design); Navigation system (Atlassian); Navigation Menu (shadcn/ui); Nav (Fluent UI); Service navigation (GOV.UK)
Semantic element
<nav>
Native HTML
<nav>
ARIA pattern
navigation
Research note
Link lists. Label each one if there's more than one

Layout Variations

Usage Notes

  • Use inside Header for primary site navigation.
  • For in-page section navigation, use Tabs.
  • For sidebar navigation, combine with Sidebar.
  • Keep top-level nav items to 5-7 for optimal usability. Use dropdowns for additional options.

Structure

Allowed parents
None: placed by the page template, rendered in the top layer, or used inline inside another component
