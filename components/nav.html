Nav

Primary navigation menu presenting the main site structure. Contains links to top-level pages organized as a horizontal or vertical list.

Also known as
Navbar (Bootstrap), Navigation Drawer / Top App Bar (Material), Menu (Ant), Tab Bar / Sidebar (Apple), Navigation Menu (shadcn)
Semantic element
<nav>
Category
Navigation

Usage Notes

  • Use inside Header for primary site navigation.
  • For in-page section navigation, use Tabs.
  • For sidebar navigation, combine with Aside.
  • Keep top-level nav items to 5-7 for optimal usability. Use dropdowns for additional options.
