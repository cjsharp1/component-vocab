Slider

A control for setting a value, or a range between two values, by moving a thumb along a track. Use it when the relative position matters more than the exact number, such as volume or a price range.

Also known as

Usage Notes

  • Slider means a range input only. A rotating set of slides is a Carousel.
  • Sliders are hard to set to an exact value, especially by touch. When the exact number matters, use a Number input, or add one next to the slider.
  • Show the current value and the limits. Custom sliders follow the APG Slider pattern: role="slider" with aria-valuenow, aria-valuemin and aria-valuemax, plus aria-valuetext when the number alone isn't meaningful, such as "$20 to $80".
  • Arrow keys change the value by one step, and Page Up, Page Down, Home and End make larger jumps. Dragging must not be the only way to set it (WCAG 2.5.7).
  • For a range, give each thumb its own accessible name, such as "Minimum price" and "Maximum price".
