Steps

A numbered list that shows where the user is in a multi-step process, such as checkout, and which steps are done or still to come. Mark the current step with aria-current="step".

Also known as
Stepper, Progress tracker. In design systems: Stepper (MUI); Steps (Ant Design, Chakra UI); Progress indicator (Carbon); Progress tracker (Atlassian)
Semantic element
<ol> with aria-current="step"
Native HTML
<ol>
Research note
aria-current="step". "Stepper" also names a quantity control — that is Number input.

Usage Notes

  • Use an <ol> so the number of steps and each step's position are announced, and put aria-current="step" on the current one.
  • Show completed, current and upcoming states with text or icons as well as color (WCAG 1.4.1), for example visually hidden "Completed" text in each finished step.
  • Make completed steps links only if users can safely go back to them. Upcoming steps should not be links.
  • Steps shows position in a process. For the share of a task that is done, use a Progress bar; for dated events, use a Timeline; for a quantity with + and − buttons, use a Number input.
  • A long row of steps rarely fits on a small screen. Switch to the vertical layout, or show only the current step and the count.
