Rich Text

Long-form rich text content — article bodies, descriptions, documentation. Provides appropriate typography and spacing for readable paragraphs, headings, lists, and inline elements.

Usage Notes

  • Use for blog and article body text. Wrap any long-form text in Rich Text for proper typography.
  • Don't nest other components inside Rich Text.
  • Keep max width narrow (65-75 characters per line) for optimal readability.
  • Use lead text or drop cap to visually signal the start of long-form content.
  • Use <article> only for self-contained content such as a post or a Card in a list; plain body text is a <div>.
