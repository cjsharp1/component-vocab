Code

A fragment of code or a literal value, marked up as <code>. Inline code sits in a sentence; the block variant wraps it in <pre> so whitespace is preserved. An optional copy control helps people reuse longer snippets.

Also known as
Code block, Code snippet. In design systems: Code snippet (Carbon); Code (Atlassian, Chakra UI, Radix Themes); Code Block (shadcn/ui)
Semantic element
<code>, or <pre><code> for a block
Native HTML
<code>, <pre>
Research note
Block form is a variant (R6), not a separate Code block entry. Carbon's Code snippet covers inline, single-line and multi-line.

Usage Notes

  • Use <code> for short literals in prose. For a multi-line snippet, wrap it in <pre><code> so indentation and line breaks stay intact.
  • Don't use <pre> alone for code; put the code in <code> inside it (HTML living standard).
  • If you offer a copy control, name the button for what it copies ("Copy code"), and confirm success without relying on color alone.
  • Escape angle brackets in the displayed source so the browser doesn't treat them as markup.
  • Syntax highlighting is presentation. Keep the underlying text selectable and copyable.
