Tooltip

A contextual hint that appears on hover or focus near a trigger element. Provides brief explanatory text without cluttering the interface.

Usage Notes

  • Use for brief hints (a few words or a single sentence). For rich content, use Popover.
  • Keep text short. If you need more than two lines, consider a different pattern.
  • Tooltips should appear on hover or focus, not on click. For click-triggered content, use Popover or Menu button.
  • Ensure the trigger element is keyboard-accessible and the tooltip is announced by screen readers.
