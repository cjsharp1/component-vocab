Skip link

A link at the very start of the page that jumps past the Header and Navigation to the Main content. It usually stays hidden until it receives keyboard focus.

Also known as
In design systems: Skip Nav (Chakra UI); Skip link (GOV.UK)

Usage Notes

  • Make it the first focusable element in <body>, so the first Tab press reaches it. It is the usual way to meet WCAG 2.4.1 Bypass Blocks.
  • Hide it in a way that keeps it focusable, such as the Visually hidden pattern, and reveal it on :focus. display: none and the hidden attribute remove it for keyboard users too.
  • When focused it must be visible with a clear focus indicator (WCAG 2.4.7) and not covered by a sticky Header (WCAG 2.4.11 Focus Not Obscured).
  • Point it at an element with a matching id, usually Main. Adding tabindex="-1" to the target makes focus move there reliably, so the next Tab continues from the content.
  • Use text that names the destination. One link is usually enough; a long list of skip links brings back the problem it was meant to solve.
