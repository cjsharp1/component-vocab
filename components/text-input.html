Text input

A single-line field for short free text, such as a name, email address or city. For answers that may run to several lines, use a Textarea.

Also known as
In design systems: Text Field (MUI, Radix Themes); Form control (Bootstrap); Input (Ant Design, Chakra UI, shadcn/ui, Fluent UI); Text input (Carbon, GOV.UK); Text field (Polaris, Atlassian); Text fields (Apple HIG)
Semantic element
<input type="text">, or a more specific type such as email, tel or url
Native HTML
<input type="text">

Usage Notes

  • Pick the most specific type (email, tel, url) and add inputmode where it helps, so mobile keyboards match. For digits that aren't amounts, like card numbers, use inputmode="numeric" rather than type="number"; for a quantity with +/- buttons, use a Number input.
  • Add autocomplete to fields that collect the user's own details, such as name, email and address (WCAG 1.3.5 Identify Input Purpose).
  • Every field needs a visible Label. Placeholder text isn't a substitute, and format help belongs in a hint linked with aria-describedby.
  • Show errors as text next to the field, set aria-invalid="true" and link the message with aria-describedby (WCAG 3.3.1 Error Identification).
  • Size the field to the expected answer: short for a postcode, full width for a street address.
