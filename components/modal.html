Modal

An overlay dialog that requires user attention or action. Appears above the page content, blocking interaction with the background until dismissed.

Also known as
Modal (Bootstrap), Dialog (Material), Modal (Ant), Sheet/Alert (Apple), Dialog (shadcn)
Semantic element
<dialog> or <div> with role="dialog"
Category
Forms & Feedback

Usage Notes

  • Use sparingly — modals interrupt the user.
  • For non-blocking notifications, use Toast.
  • For side panels, use Drawer.
  • Always provide a way to dismiss (close button, backdrop click, or Escape key).
