Heading

A title that starts a section of content, marked up as h1 to h6. The level follows the page outline; how large it looks is a separate setting.

Usage Notes

  • Choose the level from the outline, not the look: one h1 for the page title (usually in the Hero), h2 for sections, h3 inside them, without skipping levels. Set the size separately.
  • Screen reader users often move through a page by headings, so each heading should describe what follows (WCAG 1.3.1 Info and Relationships, 2.4.6 Headings and Labels).
  • Don't use a heading element just to make text large or bold. Use a text style instead.
  • Keep an eyebrow or subtitle outside the heading element, for example in a <p> before it, so the heading's text stays short when listed out of context.
  • A Section that has a heading becomes a named region when it points to the heading with aria-labelledby.
