Image

An image, illustration, diagram, or code snippet accompanied by a caption. Used for visual content that needs attribution or explanation.

Usage Notes

  • Use Image for any visual; a caption renders it as a figure. For image and text side by side, use the horizontal media variant of Card. For collections of figures, use the Gallery (collection) layout config.
  • Always use semantic <figure> and <figcaption> elements.
  • Caption text should describe or attribute the image, not repeat information already visible.
  • For diagrams and charts, caption should help screen reader users understand the content.
