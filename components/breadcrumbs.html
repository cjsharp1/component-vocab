Breadcrumbs

A hierarchical trail showing the user's location within the site structure. Provides orientation and quick navigation to parent pages.

Also known as
Breadcrumb, Breadcrumb trail. In design systems: Breadcrumbs (MUI, Atlassian, GOV.UK); Breadcrumb (Bootstrap, Ant Design, Carbon, Chakra UI, shadcn/ui, Fluent UI)
Semantic element
<nav> with aria-label="breadcrumb"
Native HTML
<nav aria-label="Breadcrumb"><ol>
ARIA pattern
Breadcrumb
Research note
aria-current="page" on the last item

HTML Outline

A high-level skeleton showing the semantic elements and ARIA this component uses. Illustrative, not production markup.

<nav aria-label="Breadcrumb">
  <ol>
    <li><a href="/">Home</a></li>
    <li><a href="/guides">Guides</a></li>
    <li><a href="/guides/setup" aria-current="page">Setup</a></li>
  </ol>
</nav>

Layout Variations

Usage Notes

  • Place at the top of page content, below the Header.
  • Last item is the current page and should not be a link.
  • Don't use on single-level sites.
  • For very deep hierarchies, consider truncating middle items with an ellipsis.

Structure

Allowed parents
None: placed by the page template, rendered in the top layer, or used inline inside another component
