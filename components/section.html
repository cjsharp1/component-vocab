Section

A thematic grouping of content that forms a distinct part of a page. Typically spans full width and contains one or more content components within a constrained content width.

Also known as
In design systems: Section (Polaris, Radix Themes)

Usage Notes

  • Every major page block should be wrapped in a Section.
  • Set the content width to keep text centered and readable.
  • Add an id attribute for anchor link navigation.
  • Width is a Section setting (narrow, content, wide, full), not a separate Container block.
