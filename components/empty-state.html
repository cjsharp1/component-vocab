Empty state

A message shown where content would be but isn't yet, such as an empty list or a search with no results. It says why the area is empty and offers the next step.

Also known as
In design systems: Empty (Ant Design, shadcn/ui); Empty state (Polaris, Atlassian); Empty State (Chakra UI)
Semantic element
<div> with a heading, text and an action
Category
C. Content display

Usage Notes

  • Say what is empty and what to do next. A bare "No data" leaves people guessing whether something failed.
  • Treat the illustration as decorative (aria-hidden="true" or an empty alt); the heading and text carry the message.
  • When it replaces results after a search or filter change, announce it in a role="status" region so screen reader users know the update happened (WCAG 4.1.3 Status Messages).
  • Pick the heading level from where it sits in the outline, not from the size you want (see Heading).
  • Use Empty state for missing content. Use Alert for errors that need attention, and Skeleton or Spinner while content is still loading.
