Call to action

A prominent call-to-action block designed to convert visitors. Contains a compelling headline, supporting text, and one or more buttons urging the user to take action.

Also known as
CTA
Semantic element
<section>
Research note
Often abbreviated CTA. Names a section with a primary action, not a lone Button.
Industry sources
Preline Call-to-Action Sections; Flowbite CTA Sections
Category
J. Page patterns

HTML Outline

A high-level skeleton showing the semantic elements and ARIA this component uses. Illustrative, not production markup.

<section class="call-to-action" aria-labelledby="cta-title">
  <h2 id="cta-title">Ready to start?</h2>
  <p>Short supporting line.</p>
  <div class="button-group">
    <a href="/signup">Sign up</a>
  </div>
</section>

Usage Notes

  • Use for conversion-focused sections lower on a page.
  • Limit to 1-2 per page.
  • For page-top promotion, use Hero. For announcements, use the announcement variant of Alert.
  • Keep the headline action-oriented and benefit-focused.
