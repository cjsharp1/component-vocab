Hero

A large introductory area typically placed at the top of a page. Contains a prominent headline, supporting text, and one or more calls to action. Sets the tone and primary message for the page content that follows.

Also known as
Jumbotron
Semantic element

Native HTML

"Banner" is a landmark, so avoid it

Usage Notes

  • Use Hero as the first content component on a page, inside a <section>.
  • Limit to one Hero per page. For secondary promotional areas lower on the page, use Call to action instead.
  • When using a background image, always provide an overlay or ensure text contrast meets WCAG AA.
  • The "Split" layouts work best with a side image or illustration, not a background image.
