Stack

A wrapper that lays out its children in a vertical column with one consistent gap between them. Use it to space a group of blocks instead of adding margins or empty spacer elements.

Also known as
In design systems: Stack (MUI, Polaris, Atlassian, Chakra UI); Stacks (Bootstrap); Space (Ant Design); Flex (Radix Themes)

Usage Notes

  • Stack only sets spacing and adds no meaning. Render a <div>, or a <ul> or <ol> when the children are a list of like items.
  • Build it with flexbox or grid and gap, so space appears only between children and never before the first or after the last.
  • Section and Slot already have a stack gap setting. Add a separate Stack only for a group that needs a tighter or looser gap, such as a heading with its intro text.
  • Take gap values from the spacing scale rather than one-off sizes, so spacing stays consistent across the page.
  • For side-by-side columns, use Grid. For a row of related actions, use Button group.
