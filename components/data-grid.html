Data grid

An interactive table where people move between cells with the arrow keys and can sort, select or edit. Use it for spreadsheet-like work; for data that people only read, use a Table.

Usage Notes

  • Use a Table when people read data and a Data grid only when they need to act on cells. role="grid" changes keyboard behavior: Tab enters the grid once, and the arrow keys move between cells.
  • Follow the APG Grid pattern: the current cell has tabindex="0" and the rest -1 (roving tabindex), with Home, End, Page Up and Page Down for large grids.
  • Mark the sorted column with aria-sort on its header, and put the sort control inside the header as a <button>.
  • For editable cells, Enter or F2 starts editing and Escape cancels, handing the arrow keys back to cell navigation.
  • Data grid is named apart from Grid, the CSS layout primitive. Use role="treegrid" when rows can expand to show child rows.
