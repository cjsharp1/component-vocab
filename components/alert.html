Alert

An inline feedback message communicating the result of a user action or system state. Success, warning, error, or informational messages that appear in context.

Also known as
Alert (Bootstrap), Snackbar (Material, partial), Alert (Ant), Inline Alert (Apple), Alert (shadcn)
Semantic element
<div> with role="alert"
Category
Forms & Feedback

Usage Notes

  • Use for contextual feedback (form validation, system status).
  • For editorial emphasis, use Callout.
  • For temporary non-blocking messages, use Toast.
  • Position alerts near the relevant context (above a form, at the top of a page section).
