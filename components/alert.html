Alert

An inline feedback message communicating the result of a user action or system state. Success, warning, error, or informational messages that appear in context.

Also known as
Notification, Banner, Callout, Message. In design systems: Alert (MUI, Ant Design, Chakra UI, shadcn/ui); Alerts (Bootstrap); Notification (Carbon); Banner (Polaris, Atlassian); Callout (Radix Themes); Message bar (Fluent UI); Notification banner (GOV.UK)
Semantic element
<div> with role="alert"
Native HTML
role="alert" or role="status"

Usage Notes

  • Use for contextual feedback (form validation, system status).
  • For editorial emphasis, use the note variant (formerly Callout).
  • For temporary non-blocking messages, use Toast.
  • Position alerts near the relevant context (above a form, at the top of a page section).
  • Avoid the word "banner" for this: it is the name of the page header landmark.
  • Pull-quotes belong to Quote, not Alert.
