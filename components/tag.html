Tag

A short label that puts an item in a category, such as a topic on an article. If it can be selected or removed, use a Chip; for a status or a count, use a Badge.

Usage Notes

  • A Tag puts something in a category and a Badge shows a status or count. Neither is interactive. If people can select, filter with or remove it in place, it's a Chip.
  • When a tag leads to a page listing everything in that category, make it an <a href>; otherwise use a <span>. Don't attach a click handler to a span.
  • Put a set of tags in a <ul> so screen readers announce how many there are. Add a visible or visually hidden label such as "Topics" if the list needs context.
  • Don't rely on color alone to tell categories apart (WCAG 1.4.1 Use of Color), and keep the text at 4.5:1 contrast against the tag background (WCAG 1.4.3 Contrast, Minimum).
  • This component is not called Label, because Label is reserved for the form element.
