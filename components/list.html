List

A structured list of items — features, benefits, steps, or any enumerated content. More visually styled than a plain HTML list.

Also known as
In design systems: List (MUI, Carbon, Chakra UI, Fluent UI); List group (Bootstrap); List (deprecated) (Ant Design); Ordered list / Unordered list (Polaris); Lists and tables (Apple HIG)
Semantic element
<ul> or <ol>
Category
C. Content display

Usage Notes

  • Use for feature lists, step sequences, or any ordered/unordered enumeration.
  • For expandable items, use Accordion. For key-value data, use Description list.
  • Keep list items concise. If items have substantial content, consider using Accordion or Card.
  • Icon-led lists work well for feature benefits (checkmark icons convey completion or inclusion).
