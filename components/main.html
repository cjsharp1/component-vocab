Main

The landmark that holds the primary content of the page, everything except the shared Header, Navigation and Footer. Use one visible <main> per page.

Usage Notes

  • Use one <main> per page. HTML allows more only when all but one carry the hidden attribute.
  • Put only content unique to the page inside it. The site Header, Navigation and Footer sit outside, so the banner and contentinfo landmarks stay separate from main.
  • Place it directly in <body> (a wrapping <div> is fine). HTML does not allow it inside <article>, <aside>, <header>, <footer> or <nav>.
  • Give it an id and point the Skip link at it, so keyboard users can bypass repeated navigation (WCAG 2.4.1 Bypass Blocks).
  • Start it with the page's h1, so jumping to the main landmark and jumping to the first heading land in the same place.
