Usage Notes

  • Provide captions for prerecorded speech (WCAG 1.2.2) with <track kind="captions">. When the picture carries information the audio doesn't, add audio description or a transcript (WCAG 1.2.3, 1.2.5).
  • Don't autoplay with sound. Sound that plays for more than three seconds needs a way to stop it (WCAG 1.4.2), and moving video that starts on its own and lasts more than five seconds needs a way to pause it (WCAG 2.2.2).
  • Keep the controls attribute unless you build custom controls. Custom buttons need accessible names and must work with the keyboard.
  • Set width and height or a CSS aspect-ratio so the page doesn't shift while the video loads, and use preload="metadata" with a poster to keep the first load light.
  • Use Video for files you host. For YouTube, Vimeo and other services that provide an iframe, use Embed.
