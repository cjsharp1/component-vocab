File

A link to a document people can download, such as a PDF or spreadsheet, shown with its file type and size so they know what they will get. To let people send you a file, use File upload instead.

Usage Notes

  • Put the file type and size in the link text or right after it, as in "Annual report (PDF, 2.4 MB)", so people can decide before they download.
  • Name the document, not the action: "2025 annual report", not "Download" or "Click here". Several links that all say "Download" can't be told apart in a screen reader's list of links (WCAG 2.4.4).
  • The download attribute only applies to same-origin URLs. For files on another domain, browsers ignore it and may open the file instead.
  • Use File for documents you offer. To let people choose a file to send, use File upload (<input type="file">).
  • When the content is meant to be read on screen, prefer an HTML page and offer the file as an extra format.
