Textarea

A multi-line field for longer free text, such as a message or a description. Use it when the answer may run past one line; for short values, use a Text input.

Also known as
Textbox. In design systems: Textarea Autosize (MUI); Text area (Polaris, Atlassian); Textarea (Chakra UI, shadcn/ui, Fluent UI, GOV.UK); Text Area (Radix Themes); Text views (Apple HIG)

Usage Notes

  • Use a Textarea when the answer can be longer than a line. Use a Text input for short single-line values; Enter in a Textarea adds a line break instead of submitting the form.
  • Set rows to suit the expected length. If the height grows with the content, still allow vertical resizing so people can see more of what they wrote.
  • With a character limit, show how many characters remain and announce the count through a polite live region after typing pauses, not on every keystroke. Letting people go over and showing an error is kinder than maxlength, which silently cuts off pasted text.
  • Give it a visible <label> and link hints and errors with aria-describedby, as for a Text input.
  • The alias "Textbox" is the ARIA role a <textarea> already has (textbox with aria-multiline). The component keeps the HTML element's name.
