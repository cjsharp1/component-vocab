Grid

A multi-column layout system for arranging child components side by side. Provides responsive column structure that reflows on smaller screens.

Also known as
Grid system (Bootstrap), Row/Col (Ant)

Usage Notes

  • Use Grid to arrange Card Lists, Feature Lists, or any repeating content.
  • Prefer auto-fit for content-driven layouts where item count varies.
  • Grid is a layout utility — it doesn't add visual styling to its children.
