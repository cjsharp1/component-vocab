Menu button

A menu of actions or navigation links revealed from a trigger element. Appears as a floating list on click.

Also known as
Dropdown menu. In design systems: Menu (MUI, Polaris, Chakra UI, Fluent UI); Dropdowns (Bootstrap); Dropdown (Ant Design); Menu buttons (Carbon); Dropdown menu (Atlassian); Dropdown Menu (Radix Themes, shadcn/ui); Pull-down buttons (Apple HIG)
Semantic element
<div> with role="menu"
Native HTML
<button aria-haspopup>

Usage Notes

  • Use for action menus attached to buttons or icons. For primary navigation, use Navigation.
  • For rich informational content, use Popover. Menu button is best for lists of actions or links.
  • Ensure keyboard navigation is supported: arrow keys to navigate items, Enter/Space to activate, Escape to close.
  • Dismiss on outside click or when an action is selected.
