Spinner

A generic loading or processing animation indicating that work is in progress. Used when duration is unknown.

Also known as
Spinner (Bootstrap), Circular Progress indeterminate (Material), Spin (Ant), Activity Indicator (Apple), Spinner (shadcn)
Semantic element
<div> with role="status"

Usage Notes

  • Use for indeterminate loading when duration is unknown. For known progress, use Progress.
  • For content-shaped loading states, use Skeleton instead.
  • Provide accessible labeling with role="status" and an aria-label or visually-hidden text.
  • Full-page overlays block all interaction. Use sparingly and only for critical operations.
