Pagination

Page-by-page navigation for content split across multiple pages. Provides numbered pages, previous/next, and optionally first/last.

Also known as
In design systems: Pagination (MUI, Bootstrap, Ant Design, Carbon, Atlassian, Chakra UI, shadcn/ui, GOV.UK); Page controls (Apple HIG)
Semantic element
<nav> with aria-label="pagination"
Native HTML
<nav aria-label="Pagination"><ul>
Research note
aria-current="page"
Category
E. Wayfinding and sequence

HTML Outline

A high-level skeleton showing the semantic elements and ARIA this component uses. Illustrative, not production markup.

<nav aria-label="Pagination">
  <ul>
    <li><a href="?page=1">Previous</a></li>
    <li><a href="?page=1">1</a></li>
    <li><a href="?page=2" aria-current="page">2</a></li>
    <li><a href="?page=3">Next</a></li>
  </ul>
</nav>

Usage Notes

  • Use at the bottom of paginated content (blog archives, search results).
  • For single-item navigation (next/prev article), use the component-nav pattern.
  • Show 5-7 page numbers maximum. Use ellipsis for longer lists.
  • Disable Previous on the first page and Next on the last page.
