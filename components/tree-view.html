Tree view

A hierarchical list whose parent items expand and collapse, such as folders in a file browser. Use it when people need to browse and select within a hierarchy; for site navigation, nested lists of links are simpler.

Also known as
In design systems: Tree (Ant Design, Fluent UI); Tree view (Carbon); Tree View (Chakra UI); Outline views (Apple HIG)

Usage Notes

  • The ARIA tree role comes with a full keyboard model from the ARIA Authoring Practices: one tab stop, arrow keys to move and to expand or collapse, Home and End, and type-ahead. Use the role only if you build all of it.
  • For site navigation, use nested <ul> lists of links inside Navigation, with Disclosure buttons for sections. Links in a tree lose their normal tab and link behavior.
  • Set aria-expanded on parent items only; leaf items have no expanded state. Give the tree an accessible name with aria-label or aria-labelledby.
  • For rows with several columns that can also expand, use a Data grid (the treegrid pattern) instead.
  • Don't rely on indentation alone to show nesting. Pair it with expand icons, and with indent guides when the tree is deep.
