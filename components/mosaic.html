Mosaic

An asymmetric, mixed-size layout of content blocks. Unlike a uniform Grid, items have intentionally varied sizes to create visual interest and hierarchy.

Usage Notes

  • Use for portfolios, image galleries, or content that benefits from visual variety. For uniform grids, use Grid. For image-only collections with captions, use Gallery (Figure collection).
  • Implement with CSS Grid using grid-template-columns and grid-column / grid-row spanning.
  • Plan the layout pattern in advance — random patterns can look chaotic if not carefully designed.
  • Ensure sufficient contrast for text overlays on images in mosaic cards.
  • On mobile, mosaic layouts typically revert to a single-column or simpler 2-column grid.
