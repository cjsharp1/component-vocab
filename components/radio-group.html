Radio group

A set of options, all visible at once, where people pick exactly one. Use it for a small number of choices; for long lists, use a Select.

Also known as

Usage Notes

  • Use a Radio group when people must choose exactly one option and seeing every option helps them decide. Use Checkbox when several can be chosen, and a Select when the list is long.
  • Wrap the radios in a <fieldset> with a <legend> and give them the same name. The group is the unit; a single radio on its own means nothing.
  • Native radios move and select with the arrow keys, and Tab leaves the group, as in the APG Radio Group pattern. Custom versions must keep that behavior.
  • A chosen radio can't be cleared. Add an option such as "None" when no answer is valid, and avoid preselecting an answer when the choice matters.
  • A Segmented control offers the same single choice as a compact row of buttons. It suits switching views or settings; use a Radio group for questions in a form.
