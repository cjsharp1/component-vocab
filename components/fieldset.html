Fieldset

Groups related form controls under a caption, such as the fields of an address or a set of radio buttons. Use it whenever several controls answer one question or belong together.

Usage Notes

  • Use a Fieldset for checkboxes or radio buttons that answer one question, and for groups like an address or a date of birth. A Radio group is built on one.
  • Keep the <legend> short, since screen readers may repeat it with each control in the group. Put longer guidance in a hint linked with aria-describedby.
  • When the group is the only question on the page, the legend can contain the page's <h1> so the heading isn't read twice.
  • Setting disabled on the fieldset disables every control inside it.
  • Don't wrap a single control in a fieldset; a Label is enough. Avoid nesting fieldsets, which makes the announced names long and confusing.
