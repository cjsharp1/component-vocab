Visually hidden

A utility that hides text on screen but keeps it available to screen readers. Use it to name icon-only controls or to add context that sighted users get from the layout.

Also known as
Screenreader only. In design systems: Visually hidden (Bootstrap, Atlassian); Visually Hidden (Chakra UI, Radix Themes)

Usage Notes

  • Hide the text with a clipping pattern (position: absolute; width: 1px; height: 1px; overflow: hidden; clip-path: inset(50%); white-space: nowrap). display: none, visibility: hidden and the hidden attribute hide it from screen readers too.
  • Use it only when sighted users get the same information another way, such as the icon on an icon-only Button. Text everyone needs should stay visible.
  • Hidden text is translated along with the rest of the page by browser translation tools, which often skip aria-label.
  • Don't use it on focusable elements unless they become visible on focus, like a Skip link. A focused element nobody can see fails WCAG 2.4.7 Focus Visible.
  • For the opposite case, content that is visible but should be skipped by screen readers, use aria-hidden="true", as on a decorative Icon.
