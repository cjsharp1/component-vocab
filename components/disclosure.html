Disclosure

A control that shows and hides one section of content, such as extra help under a form field. Use <details> and <summary>; for a set of related sections, use an Accordion.

Usage Notes

  • Native <details> and <summary> work with the keyboard and screen readers without any script. Don't put links or other controls inside the <summary>.
  • If you build it from a button instead, set aria-expanded on the button and show or hide the content it controls, as in the ARIA Authoring Practices Disclosure pattern.
  • Use one Disclosure for a single optional section. For several related sections, use an Accordion; to switch between views of the same space, use Tabs.
  • Write a summary that says what is inside, such as "Help with your reference number", not just "More".
  • Don't hide content that most people need to complete the task. Leave it visible instead.
