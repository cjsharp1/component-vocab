Color picker

A control for choosing a color, either the native <input type="color"> or a panel with a color area, hue slider and value field. Use it when any color is allowed; for a few fixed colors, use a Radio group of swatches.

Usage Notes

  • Start with the native <input type="color">. It opens the system picker, works with the keyboard, and always returns a hex value such as #2350d1.
  • Show the value as text next to the swatch, ideally in an editable field, so people can paste an exact color and the choice isn't shown by color alone (WCAG 1.4.1).
  • If only a few colors are allowed, such as product colors, use a Radio group styled as swatches and give each option a name ("Navy", not just a color).
  • A custom color area has no native role and needs dragging. Pair it with value fields or sliders built on the APG Slider pattern so the color can be set without dragging (WCAG 2.5.7).
