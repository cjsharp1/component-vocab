Header

The top-level site header containing the brand identity and primary navigation. Persists across pages as a global landmark.

Also known as
In design systems: App Bar (MUI); UI shell header (Carbon); GOV.UK header (GOV.UK)
Semantic element
<header>
Native HTML
<header>
ARIA pattern
banner (only when scoped to body)
Research note
Inside main/section/article it is not a landmark
Category

Layout Variations

Usage Notes

  • Place as the first child of <body>.
  • Use the Navigation component inside Header for the navigation links.
  • Sticky headers should have a solid background or backdrop blur.

Structure

Allowed parents
None: placed by the page template, rendered in the top layer, or used inline inside another component
