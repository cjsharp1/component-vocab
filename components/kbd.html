Kbd

A key or shortcut shown as the user would press it, marked up as <kbd>. Use one element per key; put separators between keys in a combination so the order stays clear when read aloud.

Also known as
Keyboard key. In design systems: Kbd (Chakra UI, Radix Themes, shadcn/ui)

Usage Notes

  • Use <kbd> only to show keys or shortcuts people should press. Don't use it for product names or generic badges.
  • For a combination, nest a <kbd> per key (or use adjacent keys with a text "+") so screen readers hear each key, not one run-on word.
  • Always say what the shortcut does in nearby text. The styled key alone is not enough for people who can't see the visual treatment.
  • Kbd documents a shortcut; the page still needs a real keyboard handler if the shortcut should work.
  • Prefer plain key names (Ctrl, Shift) when the audience may not know platform glyphs, or match the user's platform when you can detect it.
