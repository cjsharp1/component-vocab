Button

A control that performs an action on the current page: submits a form, opens a dialog, saves or deletes. If the result is going somewhere else, use a Link instead.

Usage Notes

  • Use <button> for actions and <a href> for navigation. A link styled as a button is still a Link.
  • Start the label with a verb ("Save changes", not "OK"). Icon-only buttons need an accessible name, such as visually hidden text.
  • Keep one primary button per view or section so the main action is obvious.
  • Inside a form, set type="button" on buttons that shouldn't submit; the default type is submit.
  • Avoid disabling a button without saying why. Prefer leaving it enabled and explaining what is missing when it's pressed.
