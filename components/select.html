Select

A native drop-down list for choosing one option from a known set, built on <select>. Use it when there are too many options for a Radio group and people don't need to type to find one.

Also known as
Dropdown, Select input. In design systems: Select (MUI, Bootstrap, Ant Design, Polaris, Atlassian, Chakra UI, Radix Themes, shadcn/ui, GOV.UK); Dropdown (Carbon, Fluent UI); Pop-up buttons (Apple HIG)

Usage Notes

  • Use a Select for one choice from a list of known options. With about five options or fewer, a Radio group shows them all and saves a click.
  • If people need to type to find an option in a long list, use a Combobox. Avoid rebuilding <select> with custom markup for looks; the native element brings keyboard, mobile and screen reader support for free.
  • Give it a visible <label>. A first option such as "Choose…" is not a label.
  • Don't submit the form or go to another page when the value changes. A change of context on input needs a warning first (WCAG 3.2.2).
  • "Dropdown" is retired as a name because it could mean a Select or a Menu button. For a list of actions, use a Menu button.
