Link

Text that takes the user to another page, another place on the same page, or a file. If the control performs an action on the current page instead, use a Button.

Usage Notes

  • Use <a href> for anything that changes the URL or moves to another place on the page. An <a> without href is not focusable and is not announced as a link.
  • Write link text that makes sense on its own (WCAG 2.4.4). Avoid "Click here" and "Read more" unless the surrounding sentence or visually hidden text supplies the context.
  • In body text, don't mark links by color alone (WCAG 1.4.1). Keep the underline or another visible cue.
  • A link styled as a button is still a Link: it is activated with Enter, not Space, and screen readers announce it as a link. For actions, use a Button.
  • If a link opens a new tab or downloads a file, say so in the text or with an icon that has a text alternative. For downloads, see File.
