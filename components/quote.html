Quote

Text quoted from another source, marked up as <blockquote> with an optional attribution. Its pull quote variant repeats a line from the page in large type for emphasis.

Also known as
Block quote, Pull quote. In design systems: Blockquote (Chakra UI, Radix Themes)

Usage Notes

  • Use <blockquote> only for quoted text, never just to indent. For a short quote inside a sentence, use <q>.
  • Put the attribution in a <figcaption> inside a <figure>, outside the <blockquote>. <cite> marks the title of a work, not the person's name.
  • A pull quote repeats text already on the page, so hide the duplicate from screen readers with aria-hidden="true" and don't mark it up as a <blockquote>.
  • Add decorative quotation marks with CSS or an aria-hidden graphic so they aren't read aloud.
  • For a customer quote with a name, photo and role, use Testimonial.
