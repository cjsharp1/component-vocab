Skeleton

A placeholder loading state that mimics the shape of content to come. Shows the layout structure before real content loads.

Also known as
Skeleton loader. In design systems: Skeleton (MUI, Ant Design, Atlassian, Chakra UI, Radix Themes, shadcn/ui, Fluent UI); Placeholders (Bootstrap)
Semantic element
<div> with aria-busy="true"

Usage Notes

  • Use when content takes more than 300ms to load. For indeterminate loading without showing layout, use Spinner.
  • Match the skeleton shape to the actual content layout. Users should recognize what's loading.
  • Consider a pulse or wave animation to indicate activity, but ensure it is not distracting.
  • Use aria-busy="true" and provide an accessible label like "Loading content" for screen readers.
