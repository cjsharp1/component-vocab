Number input

A field for entering a number, often with minus and plus buttons that step the value. Use it for amounts people count, such as a quantity; for digit strings like postcodes, use a Text input.

Also known as
Quantity, Counter, Nudger. In design systems: InputNumber (Ant Design); Number input (Carbon); Number field (Polaris); Number Input (Chakra UI); Spin button (Fluent UI); Steppers (Apple HIG)

Usage Notes

  • This is the quantity control that is sometimes called a stepper. A sequence of numbered stages in a process is Steps.
  • Use type="number" only for amounts. Card numbers, postcodes and phone numbers aren't counted; use a Text input with inputmode="numeric".
  • Set min, max and step, and state the limits in the hint so people know them before they see an error.
  • Custom versions follow the APG Spinbutton pattern: role="spinbutton" with aria-valuenow, aria-valuemin and aria-valuemax, Up and Down arrows to step, and typing still allowed.
  • Give the minus and plus buttons accessible names, such as "Decrease quantity", and targets of at least 24 by 24 CSS pixels (WCAG 2.5.8).
