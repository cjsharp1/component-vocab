Label

The visible name of a form control, tied to it so that clicking the text focuses the control and screen readers announce the name. Every input, select and textarea needs one.

Usage Notes

  • The name Label is reserved for the form element. For a short category marker use a Tag, and for a status use a Badge.
  • Connect it with for matching the control's id, or by wrapping the control. Clicking the label then focuses or toggles the control, which also makes small checkboxes easier to hit.
  • Keep the label visible. Placeholder text is not a label: it disappears when people type and often has low contrast (WCAG 3.3.2 Labels or Instructions).
  • If the accessible name differs from the visible text, it must contain that text (WCAG 2.5.3 Label in Name), so voice control users can say what they see.
  • Mark either the required fields or the optional ones and say what the marker means. Add the required attribute so the requirement is announced.
