Checkbox

A box that people tick to turn one option on or off, or to pick any number of options from a set. Use a Switch instead when the change takes effect immediately.

Usage Notes

  • Use a Checkbox when each option stands alone and any combination is valid. When exactly one option must be chosen, use a Radio group.
  • Put related checkboxes in a <fieldset> whose <legend> asks the question. Each box still needs its own <label>.
  • Wrap the input in its <label> or link them with for, so clicking the text toggles the box. This also gives a larger target (WCAG 2.5.8).
  • Use the indeterminate state only for a parent box whose children are partly checked. It is set with script (indeterminate = true) and is not a submitted value.
  • An unchecked box sends nothing with the form. When agreement is required, use required and an error that says what to do, such as "Confirm that you agree to the terms".
