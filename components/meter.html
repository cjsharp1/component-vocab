Meter

Shows a measurement within a known range, such as disk usage, password strength or battery level. Use <meter> for a value that can go up or down; for progress toward finishing a task, use a Progress bar.

Usage Notes

  • Use a Meter for a measurement in a fixed range and a Progress bar for how much of a task is done. <meter> and <progress> are different elements with different meanings.
  • Set min, max and value, and use low, high and optimum to mark good and bad ranges. A custom meter needs role="meter" with aria-valuemin, aria-valuemax and aria-valuenow, as in the APG Meter pattern.
  • Give it an accessible name with a <label>. If the number alone isn't meaningful, add aria-valuetext, such as "72 GB of 100 GB".
  • Show the value as text too, and don't use color alone to say a value is good or bad (WCAG 1.4.1 Use of Color). Keep the fill at 3:1 contrast against the track (WCAG 1.4.11 Non-text Contrast).
  • A Meter only displays a value. If people should set it, use a Slider.
