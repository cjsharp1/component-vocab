Combobox

A text input with a popup list of suggestions that narrows as you type. Use it when the list is long enough that typing is faster than scrolling, or when people may enter a value that isn't in the list.

Also known as
Autocomplete, Autosuggest. In design systems: Autocomplete (MUI); AutoComplete (Ant Design); Combobox (Chakra UI, shadcn/ui, Fluent UI); Combo boxes (Apple HIG)
Semantic element

Usage Notes

  • Choose a Combobox over a Select when people know what they want and typing is faster, such as picking an airport from hundreds. For short lists, a Select or Radio group is simpler.
  • Follow the APG Combobox pattern: focus stays in the input, arrow keys move through options using aria-activedescendant, Enter picks one and Escape closes the popup.
  • Tell screen reader users how many results match, for example with a polite live region, because the list changes as they type.
  • Decide whether values outside the list are allowed and say so in the hint. If only listed values are valid, show an error when the typed text matches nothing.
  • <input list> with <datalist> gives native suggestions with no script, but browsers filter and style it inconsistently. Test it before relying on it.
