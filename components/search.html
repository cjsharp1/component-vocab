Search

A search landmark holding a labeled search field and a submit button. Use it for site or page search, and for controls that filter a list.

Usage Notes

  • Wrap the form in <search> so it is exposed as a search landmark. For browsers without <search> support, use <form role="search"> instead.
  • Every search field needs a label. A visually hidden <label> is fine when the button makes the purpose clear, but placeholder text is not a label (WCAG 1.3.1, 3.3.2).
  • An icon-only submit button needs an accessible name such as "Search", given with Visually hidden text or aria-label.
  • The landmark is for the search controls, not the results. Show results in Main. If a page has more than one search landmark, give each an aria-label so they can be told apart.
  • If the field shows suggestions as you type, it becomes a Combobox and should follow the ARIA Authoring Practices combobox pattern.
