Breadcrumb

A hierarchical trail showing the user's location within the site structure. Provides orientation and quick navigation to parent pages.

Also known as
Breadcrumb (Bootstrap), — (Material), Breadcrumb (Ant), — (Apple), Breadcrumb (shadcn)
Semantic element
<nav> with aria-label="breadcrumb"
Category
Navigation

Elements

Element Required Description
Path itemsYesLinks in the breadcrumb trail
SeparatorsYesVisual dividers between items (/, >, or arrow)
Current pageYesThe last item, not linked

Layout Variations

Usage Notes

  • Place at the top of page content, below the Header.
  • Last item is the current page and should not be a link.
  • Don't use on single-level sites.
  • For very deep hierarchies, consider truncating middle items with an ellipsis.
