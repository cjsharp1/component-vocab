File upload

A control for choosing one or more files from the device to send with a form, built on <input type="file">. It can add a drop zone for dragged files and a list of the files chosen.

Also known as
File input, Dropzone. In design systems: Upload (Ant Design); File uploader (Carbon); Drop zone (Polaris); File Upload (Chakra UI); File upload (GOV.UK)

Usage Notes

  • Keep the native <input type="file"> underneath any custom design. It already works with keyboards, screen readers and mobile file choosers.
  • Dragging must never be the only way to add a file. Always include a button that opens the file chooser (WCAG 2.5.7).
  • State the allowed file types and size limit in the hint before people choose, and set accept to match. Check files on the server as well.
  • When a file is rejected, name the file and the reason in the error message, such as "report.exe is not an allowed file type", and keep the other files.
  • Tell screen reader users about upload progress and completion, for example with a Progress bar and a polite live region.
