Segmented control

A row of joined segments for choosing one option from a small set, such as List or Grid view. Build it from radio inputs in a <fieldset> so it behaves like a Radio group.

Also known as
Toggle button group. In design systems: Toggle Button (MUI); Segmented (Ant Design); Content switcher (Carbon); Segmented Control (Chakra UI, Radix Themes); Toggle Group (shadcn/ui); Segmented controls (Apple HIG)
Semantic element
<fieldset> of <input type="radio">
Native HTML

Usage Notes

  • Use it for two to five short, mutually exclusive options. With more options or long labels, use a Radio group or a Select.
  • Radio inputs give the expected keyboard behavior for free: one tab stop, with arrow keys moving the selection. If you build it from buttons instead, follow the ARIA Authoring Practices radio group pattern.
  • If each option shows a different panel of content, use Tabs. A Segmented control changes a value or a view setting.
  • Icon-only segments need an accessible name each. Show the selected segment with more than a color change, and give it 3:1 contrast against the others (WCAG 1.4.1, 1.4.11).
