Feature

A single feature or benefit highlight. Presents an icon, heading, and short description to explain a capability or value proposition. Read in place, not a link to elsewhere.

Usage Notes

  • Use Feature for explaining capabilities/benefits. For content previews that link somewhere, use Card. For statistics, use Stats.
  • Icons should be consistent in size and style across all features in a collection.
  • Keep descriptions concise — 1-3 sentences. Features are meant to be scannable.
  • Common use case: landing page "Why choose us" sections with 3-4 features in a row.
