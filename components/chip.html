Chip

A compact control for a filter option or an entered value that can be selected or removed, such as a filter for "Remote" jobs or a recipient in an email field. For a static category, use a Tag.

Usage Notes

  • A Chip is interactive; a Tag and a Badge are not. If nothing happens when it's pressed, use a Tag.
  • Build a filter chip as a <button> with aria-pressed, like the APG toggle button. When only one option can be chosen, use a Radio group or Segmented control rather than chips that just look exclusive.
  • Make the remove control its own <button> with a name that includes the value, such as "Remove Paris". A bare "×" gives screen reader users nothing to go on.
  • When a chip is removed, move focus to the next chip or back to the input so keyboard users keep their place.
  • Show the selected state with more than color, such as a check mark plus a change of fill (WCAG 1.4.1 Use of Color).
