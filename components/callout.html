Callout

A visually distinct block that draws attention to specific information. Tips, notes, warnings, or pull-quotes that need to stand out from surrounding content.

Usage Notes

  • Use within Prose for editorial emphasis. For user-action feedback (form errors, success), use Alert. For quotes with attribution, use Testimonial.
  • Color coding helps users quickly identify type: blue for info, yellow/orange for warnings, red for errors, green for tips/success.
  • Use semantic elements: <aside> for notes/tips, <blockquote> for pull-quotes.
  • Include appropriate ARIA roles when needed: role="note" or role="complementary".
