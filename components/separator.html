Layout Variations

Usage Notes

  • Use between sections when visual separation is needed beyond spacing alone.
  • Vertical dividers work well in horizontal layouts, such as between toolbar buttons or sidebar sections.
  • The "None" style provides spacing without a visible line, useful when a subtle break is needed.
  • Ensure sufficient color contrast for the line in both light and dark themes.
