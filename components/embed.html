Usage Notes

  • Use for YouTube/Vimeo videos, Google Maps, tweets, or any iframe content. Always provide a fallback or description for accessibility. Maintain aspect ratio.
  • Wrap iframes in a container with padding-bottom hack or aspect-ratio CSS to maintain responsive aspect ratios.
  • Include loading="lazy" attribute on iframes to improve page load performance.
  • Consider privacy implications — third-party embeds often include tracking. Use privacy-friendly alternatives when available.
