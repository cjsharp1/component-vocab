Slot

One cell of a Grid that holds a vertical stack of content blocks. The Grid's layout preset creates and removes slots; editors see them as columns.

Usage Notes

  • Slots exist only inside a Grid. The Grid's preset (1:1, 2:1, 1:1:1) decides how many there are, so change the preset to add or remove one.
  • Put content blocks in a slot, never another Grid or a Section. Blocks that repeat items, such as a list of Cards, set their own number per row instead.
  • Render it as a plain <div>. It has no role of its own; headings inside it carry the structure.
  • Stacked order changes only the visual order. Keep the source order meaningful, because screen readers and keyboard focus follow the DOM (WCAG 1.3.2 Meaningful Sequence, 2.4.3 Focus Order).
  • Make each slot a size container (container-type: inline-size) so blocks inside respond to the slot's width, not the viewport.
