Usage Notes

  • Use for structured metadata (event details, product specs). For detailed data tables, use Table. For single numbers, use Stats.
  • Always use semantic <dl>, <dt>, <dd> elements for definition lists.
  • Keep keys short and scannable — 1-3 words. Values can be longer.
  • For event information, consider including date, time, location, price as key fields.
  • Icons should be consistent in style and color across all rows.
