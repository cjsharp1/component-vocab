component-vocab

A shared vocabulary for website components. Each name follows native HTML first, then the W3C ARIA Authoring Practices, then what most design systems already call the thing.

Components are grouped A to J. Groups A to I follow the research consensus list. Group J holds page patterns that are standard industry terms but that no UI framework in the survey ships. Each page shows wireframes, configuration options and the names 12 design systems use.

A. Page structure

  • Header Site header with branding and navigation
  • Navigation Primary navigation menu
  • Sidebar Sidebar or complementary content
  • Footer Site footer with links, legal, contact
  • Draft Search Older stacks use role="search"
  • Breadcrumbs Hierarchical location trail

B. Layout primitives

  • Section Thematic full-width page block
  • Grid Multi-column layout system
  • Draft Slot Auto-managed by Grid
  • Draft Stack Vertical flow with a consistent gap
  • Separator Visual separator between content sections
  • Draft Visually hidden Draft entry

C. Content display

  • Draft Heading Level is not size
  • Rich Text Long-form rich text content
  • Image Image/illustration with caption
  • Draft Icon Decorative icons aria-hidden
  • Avatar Small identity image for attribution, comments
  • List Structured list of items — features, steps
  • Table Tabular data display
  • Card Preview of content — image, title, excerpt, link
  • Hero Large intro area — headline, subtext, call to action
  • Draft Empty state Draft entry
  • Description list Compact key-value summary block
  • Embed Third-party content embedded inline

D. Actions and links

  • Draft Link Navigates
  • Draft Button Acts
  • Draft Button group A CTA pair is not a toolbar
  • Menu button Menu of actions or links revealed from a trigger
  • Draft Segmented control Mutually exclusive options
  • Draft Switch Takes effect immediately

E. Wayfinding and sequence

  • Tabs Switchable tabbed content panels
  • Pagination Page-by-page navigation
  • Draft Steps aria-current="step"
  • Timeline Chronological sequence of events/milestones
  • Draft Tree view Draft entry

F. Disclosure and overlays

  • Accordion Expandable/collapsible content panels
  • Draft Disclosure A single one
  • Dialog Overlay dialog requiring action
  • Draft Alert dialog Demands a response
  • Drawer Panel sliding in from a screen edge
  • Popover Floating panel of rich content triggered by click
  • Tooltip Contextual hint appearing on hover/focus

G. Feedback and status

  • Alert Inline feedback message
  • Toast Temporary non-blocking notification
  • Badge Small indicator (count, status dot) attached to an element
  • Draft Tag Static categorization
  • Progress bar Visual indicator of task/process completion
  • Spinner Generic loading/processing animation
  • Skeleton Placeholder loading state mimicking content shape
  • Draft Rating Draft entry

H. Forms

  • Form Data collection — contact, signup, search
  • Draft Text input Draft entry
  • Draft Textarea Draft entry
  • Draft Select Choose a value
  • Draft Combobox Input plus suggestion popup
  • Draft Checkbox Draft entry
  • Draft Radio group The group is the unit
  • Draft Slider Never used for a Carousel
  • Draft Number input The +/- control
  • Draft Date input Typed
  • Draft Date picker Calendar popup
  • Draft File upload Draft entry
  • Draft Color picker Draft entry

I. Collections

  • Carousel Paginated slideshow cycling through content

J. Page patterns

Standard industry section names. Not framework consensus: no UI framework in the survey ships these.

  • Feature Single feature/benefit — icon, heading, description
  • Testimonial Quote/review attributed to a person
  • Stats Single key metric displayed prominently
  • Logo cloud Row/grid of partner/client logos
  • Call to action Prominent call-to-action block
  • Pricing table Pricing plans/tiers for comparison
