component-vocab

A shared vocabulary for website components. Each name follows native HTML first, then the W3C ARIA Authoring Practices, then what most design systems already call the thing.

Components are grouped A to J. Groups A to I follow the research consensus list. Group J holds page patterns that are standard industry terms but that no UI framework in the survey ships. Each page shows wireframes, configuration options and the names 12 design systems use.

A. Page structure

  • Header Site header with branding and navigation
  • Navigation Primary navigation menu
  • Main Landmark for the page's primary content
  • Sidebar Sidebar or complementary content
  • Footer Site footer with links, legal, contact
  • Search Labeled search field and button in a landmark
  • Skip link Lets keyboard users jump past navigation
  • Breadcrumbs Hierarchical location trail

B. Layout primitives

  • Section Thematic full-width page block
  • Grid Multi-column layout system
  • Slot One Grid cell holding stacked content blocks
  • Stack Vertical flow of blocks with a consistent gap
  • Separator Visual separator between content sections
  • Visually hidden Text for screen readers, hidden on screen

C. Content display

  • Heading Section title; level follows the outline
  • Rich Text Long-form rich text content
  • Image Image/illustration with caption
  • Video Native video player with captions
  • Icon Small symbol, decorative or labeled
  • Avatar Small identity image for attribution, comments
  • Quote Quoted text with an optional attribution
  • List Structured list of items — features, steps
  • Table Tabular data display
  • Card Preview of content — image, title, excerpt, link
  • Hero Large intro area — headline, subtext, call to action
  • Empty state Explains missing content and offers a next step
  • File Link to a downloadable document
  • Description list Compact key-value summary block
  • Embed Third-party content embedded inline

D. Actions and links

  • Link Navigates to another page or location
  • Button Triggers an action on the current page
  • Button group Related buttons or links kept together
  • Menu button Menu of actions or links revealed from a trigger
  • Segmented control Pick one of a few options in a joined row
  • Switch On/off setting that applies immediately
  • Toggle button Button that stays pressed until pressed again

E. Wayfinding and sequence

  • Tabs Switchable tabbed content panels
  • Pagination Page-by-page navigation
  • Steps Shows progress through a multi-step process
  • Timeline Chronological sequence of events/milestones
  • Tree view Expandable hierarchy of nested items
  • Feed Scrolling list of articles that loads more
  • Mega menu Large panel of grouped navigation links

F. Disclosure and overlays

  • Accordion Expandable/collapsible content panels
  • Disclosure Shows and hides one section of content
  • Dialog Overlay dialog requiring action
  • Alert dialog Interrupts to confirm a consequential action
  • Drawer Panel sliding in from a screen edge
  • Popover Floating panel of rich content triggered by click
  • Tooltip Contextual hint appearing on hover/focus
  • Toggletip Click-opened bubble with a short explanation

G. Feedback and status

  • Alert Inline feedback message
  • Toast Temporary non-blocking notification
  • Badge Small indicator (count, status dot) attached to an element
  • Tag Short label that puts an item in a category
  • Chip Compact control that can be selected or removed
  • Progress bar Visual indicator of task/process completion
  • Meter Shows a measurement within a known range
  • Spinner Generic loading/processing animation
  • Skeleton Placeholder loading state mimicking content shape
  • Rating Shows or collects a score, usually as stars

H. Forms

  • Form Data collection — contact, signup, search
  • Fieldset Groups related form controls under a legend
  • Label Visible name of a form control
  • Text input Single-line field for short text
  • Textarea Multi-line field for longer text
  • Select Choose one option from a list
  • Combobox Text input with filtered suggestions
  • Checkbox Tick one or more independent options
  • Radio group Pick exactly one option from a visible set
  • Slider Set a value by moving a thumb along a track
  • Number input Enter or step a number, such as a quantity
  • Date input Type a known date, such as a date of birth
  • Date picker Choose a date from a calendar popup
  • File upload Choose files from the device to send
  • Color picker Choose a color from a swatch or panel

I. Collections

  • Carousel Paginated slideshow cycling through content
  • Data grid Keyboard-navigable table for sorting and editing

J. Page patterns

Standard industry section names. Not framework consensus: no UI framework in the survey ships these. Names were checked against marketing-block libraries (Preline, Flowbite, HyperUI and others); each page lists its sources.

  • Feature Single feature/benefit — icon, heading, description
  • Testimonial Quote/review attributed to a person
  • Stats Single key metric displayed prominently
  • Logo cloud Row/grid of partner/client logos
  • Call to action Prominent call-to-action block
  • Pricing table Pricing plans/tiers for comparison
